# Steam Chat+ для Android

Клиент Steam Chat с тем, чего нет в официальном приложении: **голосовыми звонками** в личных и групповых чатах.

## Как это работает

Протокол голосовой связи Steam не документирован и не реализован ни в SteamKit2, ни в JavaSteam. Зато веб-версия чата (`steamcommunity.com/chat`) умеет звонки через WebRTC — тот же бэкенд Valve, что и в десктопном клиенте. Приложение — нативная оболочка вокруг неё, которая добавляет всё, чего не хватает браузеру на телефоне:

| Возможность | Как сделано |
|---|---|
| Чаты, группы, каналы, звонки | Веб-чат Steam, без изменений протокола |
| Звонок не рвётся в фоне и с выключенным экраном | Foreground-сервис типа `microphone`, CPU/Wi-Fi wakelock |
| Мьют / громкая связь из шторки и с панели в приложении | Выключение треков микрофона WebRTC; `setCommunicationDevice` |
| Датчик приближения в режиме «к уху» | `PROXIMITY_SCREEN_OFF_WAKE_LOCK` |
| Нативные уведомления о сообщениях с аватаркой | Полифил `window.Notification` → Android, тап открывает нужный чат |
| Звонок переживает поворот экрана и закрытие окна | WebView живёт в процессе, а не в Activity |
| Вход по QR / Steam Guard, отправка файлов | Стандартный вход Steam, системный выбор файлов |

Звонок определяется автоматически: скрипт, внедряемый до загрузки страницы, следит за `RTCPeerConnection` и `getUserMedia`.

## Сборка

APK собирает GitHub Actions при каждом пуше в `main`:

```bash
git init && git add . && git commit -m "Steam Chat+"
git branch -M main
git remote add origin git@github.com:ArtemDNK/steam_chat_plus.git
git push -u origin main
```

Готовый APK — во вкладке **Actions → последний запуск → Artifacts**. Тег `v*` (например `git tag v1.0 && git push --tags`) дополнительно создаёт GitHub Release с APK.

### Постоянный ключ подписи (чтобы обновления ставились поверх)

Без секретов каждый запуск подписывает APK случайным debug-ключом, и новую версию придётся ставить с удалением старой. Один раз:

```bash
keytool -genkeypair -v -keystore release.jks -alias scp -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks > release.jks.b64
```

В репозитории: **Settings → Secrets and variables → Actions** добавьте `KEYSTORE_BASE64` (содержимое `.b64`), `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`scp`), `KEY_PASSWORD`.

Локально: откройте папку в Android Studio, `./gradlew assembleRelease`.

## Настройки

- **Оставаться на связи в фоне** — держит чат подключённым ради уведомлений (постоянное тихое уведомление, расход батареи). Вместе с ним отключите оптимизацию батареи — пункт там же.
- **Ширина страницы** — веб-чат Steam рассчитан на десктоп. `0` — ширина экрана; если вёрстка тесная, поставьте 700–1000: страница впишется в экран, масштаб щипком. В альбомной ориентации и на планшете обычно удобнее всего.
- **Размер текста**, **свой CSS** — подгонка под себя.
- **Десктопный User-Agent** — по умолчанию включён, чтобы Steam отдавал полный веб-чат.

## Ограничения

- Интерфейс — веб-версия Steam, не нативный: на узком экране Steam может показывать её тесновато.
- Мьют из приложения выключает микрофон на уровне треков; иконка мьюта внутри страницы Steam при этом не меняется (собеседники вас не слышат).
- Входящий звонок как в телефоне (полноэкранный) не реализован: в Steam «звонок» — это голосовой канал или приглашение в чат, оно приходит обычным уведомлением.
- Android 14+: если голосовой чат начался, когда приложение уже было свёрнуто, система может не дать включить микрофонный сервис. Подключайтесь к голосу с открытым приложением.
- Нужен актуальный Android System WebView (обновляется через Google Play).

## Требования

Android 8.0+, WebView с поддержкой WebRTC (любой современный).
