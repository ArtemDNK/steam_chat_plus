# Steam Chat+ для Android

Клиент Steam Chat с тем, чего нет в официальном приложении: **голосовыми звонками** в личных и групповых чатах.

Автор: [@ArtemDNK](https://t.me/ArtemDNK)

## Как это работает

Протокол голосовой связи Steam не документирован, зато веб-чат Steam (`steamcommunity.com/chat`) умеет звонки через WebRTC. Приложение держит веб-чат запущенным в скрытом WebView и подключается к его внутренним хранилищам (`g_FriendsUIApp`: `FriendStore`, `ChatStore`, `VoiceStore`). Весь интерфейс нативный:

- **Чаты** — недавние переписки, непрочитанное, «печатает…».
- **Группы** — групповые чаты; внутри текстовые и голосовые каналы, кто сидит в голосе.
- **Друзья** — в игре / в сети / не в сети, поиск.
- **Звонки** — текущий разговор (микрофон, звук, громкая связь, завершить), входящие, голосовые каналы групп, друзья в голосе, быстрый вызов друзей в сети.

Один вход в аккаунт; отправка, звонки и мьют идут через собственные методы Steam, поэтому собеседники видят то же, что и с компьютера. Веб-версия доступна по значку глобуса — для входа и всего, чего нет в нативном интерфейсе.

| Возможность | Как сделано |
|---|---|
| Звонок не рвётся в фоне и с выключенным экраном | Foreground-сервис типа `microphone`, CPU/Wi-Fi wakelock |
| Входящий звонок | Уведомление с «Принять» / «Отклонить» |
| Мьют / громкая связь / завершить из шторки | `VoiceStore.ToggleMicMuting`, `setCommunicationDevice`, `OnUserEndVoiceChat` |
| Нативные уведомления о сообщениях | Полифил `window.Notification` → Android |
| Steam не ставит «Отошёл», пока вы в приложении | Касания пересылаются в трекер простоя Steam |

Внутренние хранилища Steam не публичны: если Valve их переименует, нативные экраны могут перестать обновляться. Веб-версия при этом продолжит работать.

## Сборка

APK собирает GitHub Actions при каждом пуше в `main`:

```bash
git init && git add . && git commit -m "Steam Chat+"
git branch -M main
git remote add origin git@github.com:ArtemDNK/steam_chat_plus.git
git push -u origin main
```

Готовый APK — во вкладке **Actions → последний запуск → Artifacts**. Тег `v*` (например `git tag v1.0 && git push --tags`) дополнительно создаёт GitHub Release с APK.

### Постоянный ключ подписи (чтобы обновления ставились поверх)

Без секретов каждый запуск подписывает APK случайным debug-ключом, и новую версию придётся ставить с удалением старой. Один раз:

```bash
keytool -genkeypair -v -keystore release.jks -alias scp -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks > release.jks.b64
```

В репозитории: **Settings → Secrets and variables → Actions** добавьте `KEYSTORE_BASE64` (содержимое `.b64`), `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`scp`), `KEY_PASSWORD`.

Локально: откройте папку в Android Studio, `./gradlew assembleRelease`.

## Настройки

- **Оставаться на связи в фоне** — держит чат подключённым ради уведомлений (постоянное тихое уведомление, расход батареи). Вместе с ним отключите оптимизацию батареи — пункт там же.
- **Ширина страницы**, **размер текста**, **свой CSS** — относятся к веб-версии.
- **Десктопный User-Agent** — по умолчанию включён, чтобы Steam отдавал полный веб-чат.

## Ограничения

- Создание групп, приглашения, реакции, стикеры и отправка файлов — пока через веб-версию.
- Входящий звонок приходит heads-up уведомлением, полноэкранного экрана вызова нет.
- Android 14+: если голосовой чат начался, когда приложение уже было свёрнуто, система может не дать включить микрофонный сервис. Подключайтесь к голосу с открытым приложением.
- Нужен актуальный Android System WebView (обновляется через Google Play).

## Требования

Android 8.0+, WebView с поддержкой WebRTC (любой современный).
